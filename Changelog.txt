### 📅 Version History

#### 2026-10-30 — v1.3.1-beta: "The AI Rehaul"
*   **Added:** The Anime Debate Matrix was rebuilt rather than tuned. The curated roster went from **19 to 66 sheets across 22 series**, and every matchup now runs through a **20-rule interaction matrix** (`INTERACTIONS`) instead of comparing flat numbers.
*   **Added:** A matchup report that actually argues: headline call with a difficulty rating, stat-by-stat edge list, named ability interactions, a round-by-round read (early / mid / late / who is dictating), win conditions for *both* sides, and an auditable score line showing the weights used.
*   **Added:** New debate commands — `A vs B vs C` ranks a battle royale with a focus-fire read, `tier list` groups every curated sheet by tier, `top N` (and “strongest”) ranks by composite score, `random` rolls a matchup, and `<series> roster` lists the roster for a series.
*   **Changed:** Scout estimates now include Battle IQ and pick from a wider tag pool, so an unknown name still produces a full card — flagged as an estimate, as before.
*   **Added:** **Normal** — a plain conversation engine with no persona. Handles greetings, identity questions, capability questions, planning prompts, emotional check-ins, light coding-debugging structure, jokes, and a genuine arithmetic evaluator (recursive descent over `+ - * / ( )`, no `eval`). Factual questions get an honest "no knowledge base" answer that points at the Browser panel instead of inventing something.
*   **Added:** **Spicy · 18+** — flirty banter, compliments, date ideas and adult humour behind a one-time confirmation. Content stops at suggestive; explicit requests are refused in-character, and "stop" or "not comfortable" drops the flirting immediately.
*   **Added:** **Roast Pit** — playful roasting with target parsing (`roast my friend Tyler` roasts Tyler, not you), a comeback generator, backhanded hype, a "be nice" switch, and a hard rule to go after what someone does rather than who they are.
*   **Added:** **Conspiracy Corner** — subject extraction (`why does my Wi-Fi drop` becomes a theory about your Wi-Fi dropping), a three-step case, fabricated evidence, escalation on `more`, and an `is this true` path that breaks character and says it is fiction.
*   **Removed:** Academic Assistant and Pretzel Chef. Both are gone from the engine, the persona list, the default-persona setting and the docs, replaced by the four engines above.
*   **Added:** An 18+ gate dialog (`#agegate`) with what the persona does, what it will not do, and an explicit note that the confirmation is a tone check stored in this browser, not authentication.
*   **Changed:** Version strings, the page title, the ribbon, the build chip and the About/patch-notes entries read **1.3.1 BETA** / `v1.3.1-beta` / build **`b17`**. The service-worker cache moved to `pretzel-shell-v6`.
*   **Fixed:** The shell used to call `setMode(saved.aiMode)` and would have silently rendered a dead engine if a saved persona no longer existed. It now falls back to the debate matrix, and an unconfirmed Spicy default falls back to Normal instead of popping the age gate at launch.
*   **Fixed:** Settings → Reset all now re-arms the 18+ gate, so a shared machine cannot stay unlocked because it was confirmed once.
*   **Fixed:** After the first deploy a returning visitor could run the new markup with the previous engine: the worker precached an unversioned `js/ai.js` while the CDN still served the old file, and its cache-first match ignored the `?v=` query. Shell JS and CSS are now network-first, the cache is `pretzel-shell-v6`, and the page reloads once when a new worker takes control.
*   **Fixed:** During the rebuild the sheet mapper lost its speed column, which made every score `NaN` and every verdict read "Too close to call — NaN–NaN". Caught in the engine test sweep; speed is now derived per tier with a stable per-name spread.
*   **Fixed:** The interaction list repeated the same rule once per victim tag, so a single matchup could print six near-identical ability lines. It now de-duplicates per side, sorts by rule weight and caps at four.
*   **Fixed:** Roast targets kept the possessive ("friend tyler") and conspiracy headings produced "THE THE MOON CONSPIRACY"; both were corrected during the same pass, and a doubled regex escape that stopped `my` → `your` substitution was repaired at byte level.
*   **Verified:** `npm run check` exits 0. A throwaway Electron harness (git-ignored `tmp/`, deleted after the run) drove the real shell: five persona buttons, the gate blocking Spicy while leaving the panel on debate, cancel keeping it locked with nothing stored, confirm unlocking and storing `pretzel.v13.agegate=true`, the second visit skipping the gate, a full 1098-character matchup report with headline/interactions/rounds/numeric score/verdict, a battle royale ranking, a 66-sheet tier list, `18 * 7 + 4 = 130`, the honest factual-question answer, the explicit-content refusal, `Target acquired: Tyler`, the labelled conspiracy file, the Settings persona list showing exactly the five new engines, and cache `pretzel-shell-v6`.
*   **Note:** This build is committed and pushed to `main`; GitHub Pages serves it at the endpoint above.

#### 2026-10-30 — v1.3.0-beta: 1.3 BETA Is Public (56 games)
*   **Added:** The catalog grew from 16 entries to **56** across 12 genres (Arcade, Board, Coding, Puzzle, Racing, Retro, Sandbox, Shooter, Sports, Strategy, Typing, Word). New titles include Hextris, T-Rex Runner, Slope, Doodle Jump, Flappy Bird, Krunker, Shell Shockers, Surviv.io, Diep.io, Zombs Royale, Slither.io, Splix.io, Wings.io, Mope.io, Retro Bowl, Basketball Stars, Bubbles, Breakout, Sudoku, Mahjong, Wordle Unlimited, Nerdle, Hangman, Reversi, Checkers, Lidraughts, PyChess, Online Go, FreeCell, Battleship, Prince of Persia, Super Mario Bros., Windows 93, Elevator Saga, Flexbox Froggy, Grid Garden, Blockly Games, Keybr and Sandspiel.
*   **Verified before adding:** every candidate URL was probed with the project's own `checkFrame` (`manager/lib/frame-check.js`). 89 candidates were checked across three passes; 62 answered `200` with framing headers that permit an external ancestor, and the shipped 56 are drawn from those. Titles that blocked framing (`X-Frame-Options` or `frame-ancestors`), answered `403`, or served an expired certificate were left out rather than shipped as broken cards.
*   **Added:** A **New** shelf above Continue listing the titles added in this build, and a small New flag on those cards and shelf tiles.
*   **Added:** A **quick genre strip** above the catalog. It mirrors the genre list in the filter rail with live counts, filters on one tap, and stays in sync with the rail in both directions.
*   **Added:** Paged catalog rendering. Cards render **24 at a time** with a `Show N more` button and a `Showing X of Y` line. Any filter, query or sort change resets to page one; selecting a title from the palette, a shelf or a URL expands the page far enough to include it.
*   **Added:** Per-title cover art. `hueFor` hashes the game id into a stable hue that tints each card and shelf cover, so 56 tiles read as distinct artwork instead of one repeated gradient.
*   **Added:** Suggestion bundles. The admin inbox has an **Import** action that reads an exported `pretzel-suggestions` JSON file, normalises every entry, merges by id, skips duplicates and reports how many were added and skipped. Exports now carry `format` and `bundle: 2` markers so a foreign file is rejected instead of half-imported.
*   **Added:** `Tab` is trapped inside the command palette — focus cycles through the palette input and its result buttons instead of walking into the page behind the dialog.
*   **Added:** A **Use local dev gateway** preset in Settings → Proxy. It writes `http://127.0.0.1:8788/?url={url}` as the endpoint and `http://127.0.0.1:8788/` as the health URL, which is the contract `tools/proxy-dev.js` actually serves, then probes it.
*   **Changed:** Time in frame is now accumulated from visible time only. `startTicker`/`stopTicker` derive elapsed time from a paused accumulator plus a running stamp, and `syncPlayClock` banks the elapsed span on `visibilitychange`, so a background tab or minimised window stops inflating launch totals.
*   **Changed:** Settings **Import** now goes through `readSettingsBundle`: the file is parsed, filtered to keys that exist in the settings schema, coerced to each default's type, and `aiWeights` are clamped to 0–100. Unknown keys are dropped, an unreadable file is refused with the reason, and a successful import logs how many keys applied. Legacy exports (a bare settings object) still import.
*   **Changed:** Settings **Export** writes a named, versioned bundle (`format`, `version`, `exportedAt`, `build`, `settings`) as `pretzel-settings.json`, and the import file picker resets after a choice so re-selecting the same file still fires.
*   **Changed:** Version strings, the ribbon, the page title and the About tab read **1.3 BETA** / `v1.3.0-beta`, the build tag is **`b15`**, and the ribbon now says the build is live rather than local.
*   **Changed:** The service-worker cache moved to `pretzel-shell-v4` so a stale 1.2 or b14 shell cannot mix its files with the new markup, styles and catalog.
*   **Fixed:** The ribbon, the intro sheet and the patch-notes entry still described 1.3 as an unpublished local build after it was published; they now describe the live build.
*   **Fixed:** Shelf kickers were hard-coded 02 / 03 / 04 for three shelves, so adding a fourth left the sequence out of order. The New shelf takes 02 and the rest shift to 03 / 04 / 05.
*   **Fixed:** Loading a needs-proxy title directly could record the launch a second time, because the old guard read the clock's start stamp, which is now legitimately empty while the page is hidden. It reads the ticker instead.
*   **Fixed:** An early draft of the clock keyed off `document.hasFocus()`; in a visible but unfocused window the clock could sit at `00:00` and under-report silently. Moved to page visibility and verified in a harness.
*   **Fixed:** Settings import used to write the parsed JSON straight to storage and reload, so a stray key, a string where a number belonged or a non-object file went in unvalidated. It is now checked against the schema before anything is written.
*   **Fixed:** The proxy advice in the block card pointed at `data/config.json` only; it now names the local gateway path first, which is the one a tester can actually start.
*   **Verified:** `npm run check` exits 0 and the Electron smoke passes from source (title 1.3 BETA, build `v1.3.0-beta · b15`, 24 cards on page one, renderer "Electron shell", cache `pretzel-shell-v4`, cloak show/hide, hotkey registered, secondary display). A throwaway Electron harness (git-ignored `tmp/`, deleted after the run) confirmed the catalog loads 56 titles, page one holds 24 cards with `Show 24 more`, paging reaches 48 with `Showing 48 of 56`, the 13 genre chips carry live counts, filtering to Board leaves 8 Board cards and removes the pager, a 7-result search needs no pager, the New shelf lists 12 tiles with 12 flags, and the cache holds only `pretzel-shell-v4`.
*   **Note:** This build is committed and pushed to `main`; GitHub Pages serves it at the endpoint above.
